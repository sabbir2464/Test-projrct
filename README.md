# test--project

A small Node.js test project by Sabbir Hossain.

## Requirements

- Node.js
- npm

## Setup

```bash
npm install
```

This installs [`dotenv`](https://www.npmjs.com/package/dotenv) so you can load environment variables from a `.env` file.

## Project layout

| File | Purpose |
| --- | --- |
| `package.json` | Project metadata and dependencies |
| `cursor.md` | Cursor project notes |
| `.env` | Local environment variables (create this yourself; do not commit secrets) |

The package entry point is `index.js`. Add your app code there when you are ready to run it.

## Scripts

```bash
npm test
```

No tests are configured yet. `npm test` currently exits with an error until you add a test runner.
